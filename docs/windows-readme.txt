Quick Note v0.2.0-alpha.1 for Windows (x86-64)

Extract the ZIP and open Quick Note.exe. No installation is required.
This is an experimental alpha. Actual Windows window and input behavior has not
been verified on a Windows desktop. Keep a backup of your note data.

Ctrl+N               New note
Ctrl+P               Search all notes
Ctrl+F               Find in the current note
Ctrl+Alt+F           Replace in the current note
Ctrl+G / Ctrl+Shift+G Next / previous match (also F3 / Shift+F3)
Ctrl+Shift+M         Edit / Markdown preview
Ctrl+W               Delete the current note, after confirmation
Ctrl+Shift+W         Close the window and keep notes
Ctrl+Tab             Next note
Ctrl+Shift+Tab       Previous note
Tab / Shift+Tab      Indent (four spaces) / unindent while editing
F6 or Shift+F6       Move focus between the editor and note tabs
Ctrl+,               Settings and JSON themes

Notes save automatically to %LOCALAPPDATA%\Quick Note\notes.sqlite3 in UTF-8.
Closing the app preserves them. Quit and copy the entire Quick Note data folder
to make a backup. If saving fails, keep the window open and export the text.

Use Settings to import or export shareable JSON themes and UTF-8 notes.
Open Settings > Keyboard shortcuts > Open shortcuts folder to edit bindings.json.
Primary means Ctrl on Windows. Reload shortcuts or return to the app to apply edits.
